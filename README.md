# CQ · 业余无线电刷题系统

中国业余无线电台操作技术能力验证考试刷题网页，题库数据源自官方 A / B / C 类及总题库（共 1,375 题）。

## 功能特性

- **多级别题库**：支持 A 类（683 题）、B 类（1,143 题）、C 类（1,282 题）及总题库（1,375 题）
- **刷题模式**：顺序刷题（自动断点续刷）、随机刷题、背题模式（直接显示答案）
- **题型筛选**：全部题型 / 单选题 / 多选题
- **考点专项**：依据 `[P]` 考纲编号自动归类为 5 大章、29 个二级考点及三级细分考点
- **错题集与收藏集**：错题自动收录（支持做对自动移出）、一键星标收藏、专项重刷
- **随手笔记**：每道题下方支持随时记笔记，失焦自动保存并支持集中浏览
- **数据备份**：支持 JSON 导出与导入学习记录，支持深色模式

## 小程序迁移说明

项目采用纯静态架构并针对小程序迁移做了分层解耦：

- `js/storage.js`：统一存储适配层，迁移至微信小程序 / UniApp / Taro 时只需将 `driver` 中的 `localStorage` 替换为 `wx.getStorageSync` / `wx.setStorageSync` 即可。
- `js/engine.js`：零 DOM 依赖的纯 JS 筛选、洗牌、判分与考纲统计引擎，可直接复用。
- `data/questions.json` & `data/syllabus.json`：结构化 JSON 题库与考纲元数据。
